# Análisis de taxis y clima

**Proyecto académico de TripleTen** · Data Analytics y Data Science

[Ver el caso de estudio en el portafolio](https://uly100f.github.io/projects/taxis/)

## Objetivo
Este repositorio reúne la documentación del proyecto para mostrar un proceso de análisis, metodología y resultados verificables, sin presentarlo como solución empresarial en producción.

## Tecnologías
Python · pandas · SciPy · Matplotlib · Seaborn

## Hallazgos documentados
Diferencia media observada ~360 segundos; t-test p ≈ 1.54×10⁻⁷; Levene p ≈ 0.8195.

## Código y reproducibilidad
El notebook se encuentra en revisión y aún no está publicado. La página del caso resume resultados documentados en el material original.

Los archivos de datos originales **no se publican**, ya que su redistribución requiere verificar las condiciones de uso. Los archivos empleados en el análisis fueron: moved_project_sql_result_01.csv, moved_project_sql_result_04.csv, moved_project_sql_result_07.csv.

## Atribución
Proyecto desarrollado durante formación académica de ciencia de datos. Las marcas y nombres de las empresas de práctica se utilizan solo para identificar el ejercicio. Los resultados deben interpretarse en el contexto de los datos suministrados durante la formación.

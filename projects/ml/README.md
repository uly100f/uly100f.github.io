# Predicción de planes telefónicos

**Proyecto académico de TripleTen** · Data Analytics y Data Science

[Ver el caso de estudio en el portafolio](https://uly100f.github.io/projects/ml/)

## Objetivo
Este repositorio reúne la documentación del proyecto para mostrar un proceso de análisis, metodología y resultados verificables, sin presentarlo como solución empresarial en producción.

## Tecnologías
Python · pandas · scikit-learn · clasificación

## Hallazgos documentados
Random Forest accuracy en prueba: 0.785; modelo base: 0.684.

## Código y reproducibilidad
El archivo `analysis.ipynb` es una edición para portafolio que conserva las celdas de código del ejercicio académico. Se omitieron las instrucciones y comentarios de revisión, así como las salidas de ejecución.

Los archivos de datos originales **no se publican**, ya que su redistribución requiere verificar las condiciones de uso. Para reproducir el análisis, coloca los archivos correspondientes en una carpeta `data/` junto al notebook: users_behavior.csv.

## Atribución
Proyecto desarrollado durante formación académica de ciencia de datos. Las marcas y nombres de las empresas de práctica se utilizan solo para identificar el ejercicio. Los resultados deben interpretarse en el contexto de los datos suministrados durante la formación.

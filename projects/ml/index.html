01 / CONTEXTO

El problema que abordé

Una compañía de telefonía busca clasificar perfiles de consumo para orientar la recomendación de planes. El problema se plantea como una clasificación binaria a partir de las llamadas, minutos, mensajes y datos móviles consumidos.

Proyecto académico de introducción a Machine Learning. Métricas obtenidas del notebook original revisado; no corresponden a un producto empresarial.

02 / METODOLOGÍA

Cómo lo resolví

  1. Exploré el dataset de 3,214 registros y revisé la distribución de la variable objetivo.
  2. Separé los datos en entrenamiento (60%), validación (20%) y prueba (20%).
  3. Entrené árboles de decisión, Random Forest y regresión logística, comparando su exactitud.
  4. Seleccioné el modelo a partir del conjunto de validación y comprobé el desempeño final contra un modelo de clase mayoritaria.

03 / CONCLUSIONES

Hallazgos del análisis

01

Random Forest obtuvo una exactitud de validación aproximada de 0.793 y de prueba de 0.785.

02

El modelo de referencia alcanzó 0.684: diferencia de unos 10.1 puntos porcentuales a favor del modelo seleccionado.

03

La actividad demuestra el flujo básico de entrenamiento, evaluación y selección de modelos; no prueba rendimiento en producción.
